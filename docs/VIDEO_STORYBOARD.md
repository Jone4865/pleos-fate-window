# 🎬 시연 영상 콘티 (Pleos Connect Emulator)

목표: 60~90초. "차 전체가 룰렛판"이라는 차량특화성을 한눈에 보여준다.
녹화: Pleos Connect Emulator + Virtual Console(차량 상태 조작). 화면 녹화 + 나레이션/자막.

| # | 길이 | 화면 | 차량 상태(Virtual Console) | 자막/나레이션 |
| --- | --- | --- | --- | --- |
| 1 | 0–8s | 앱 홈, 참가자 4명 자동 표시 | 기어 P, 4좌석 착좌 ON | "주차 중, 차 안에서 뭐하지?" |
| 2 | 8–15s | 모드 '복불복' 선택, 시작 탭 | - | "차가 직접 진행자가 됩니다" |
| 3 | 15–18s | 실내 암전 | 조명 OFF | "운명의 창문, 시작합니다" (TTS) |
| 4 | 18–30s | 독서등이 좌석 순회 깜빡(감속) | Spotlight 순차 ON/OFF | 두구두구 효과음 |
| 5 | 30–33s | 완전 암전 (정적) | 전체 OFF | "운명은…" |
| 6 | 33–40s | 당첨 좌석만 확 점등 + 창문 오픈 | 해당 Window.Position=50 | "조수석입니다!" + 당첨음 |
| 7 | 40–50s | 미션 카드 표시 | - | "다음 간식은 당신이!" |
| 8 | 50–65s | 날씨 전환 데모 | Wiping.Mode=RAIN | "비가 오면? 창문 없이 조명만으로" (티어3) |
| 9 | 65–75s | 심사 포인트 요약 자막 | - | 차량특화성·창의성·기술활용성 |

## 녹화 팁
- Virtual Console에서 기어/착좌/와이퍼/조명/창문 상태를 바꿔가며 티어 1·2·3을 각각 한 번씩 보여주면 "모든 차에서 동작"이 전달됨.
- 창문 open 장면은 실제 액추에이터가 느리므로 1.5~2배속 편집 가능.
- 마지막에 GitHub repo URL 노출(가산점 어필).
